# Retail Sales Business Analysis using SQL

## Overview
This project analyzes a retail sales dataset using PostgreSQL to answer real business questions and generate actionable insights.

## Objectives
- Analyze sales performance
- Identify profitable categories and regions
- Discover top customers
- Analyze discount impact
- Generate business recommendations

## Dataset
- Sample Superstore Dataset
- 9,994 records
- 21 columns

## Tech Stack
- PostgreSQL
- VS Code
- SQLTools
- pgAdmin

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- HAVING
- Aggregate Functions
- Date Functions
- CTEs
- Window Functions

## Business Case Studies
- Executive Sales Summary
- Regional Performance
- Category Analysis
- Customer Analysis
- Loss-Making Products
- Discount Impact
- Monthly Sales Trend
- Shipping Mode Analysis
- State Performance
- Executive Recommendations

## Key Insights
- Technology generated the highest sales and profit.
- West was the most profitable region.
- California generated the highest profit.
- Discounts above 30% reduced profitability.
- Standard Class shipping generated the highest sales.
- November recorded peak sales.
